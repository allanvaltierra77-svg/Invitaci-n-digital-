# GLOW HOUSE — Demo de invitación digital

Demo inicial de una invitación web para Allan & Paty.

## Cómo probarla
1. Abre `index.html` en un navegador, o publica el repositorio con GitHub Pages.
2. La cuenta regresiva apunta al 5 de febrero de 2027 a las 16:00 (hora local del dispositivo).
3. El formulario RSVP es demostrativo: muestra una confirmación en pantalla, pero aún no guarda datos.

## Publicar en GitHub Pages desde el teléfono
1. Crea un repositorio público llamado `glow-house-invitacion-demo`.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre Settings → Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige `main` y `/ (root)`, guarda y espera a que GitHub publique el sitio.
